# Go tasks

Собираю здесь решения задач по Go. У каждого задания своя папка, рядом с кодом — тесты.

(1/) — типы данных, преобразование значений в строки и SHA-256 с солью `go-2024`.

Версия Go указана в [go.mod](go.mod). Команды ниже запускаются из папки с этим файлом.

Запустить первое задание:

```bash
go run ./1
```

Проверить все задания:

```bash
go test -v ./...
```
